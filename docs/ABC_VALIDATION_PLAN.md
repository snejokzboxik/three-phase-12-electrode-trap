## Что сравниваем

| Модель | Определение |
|---|---|
| A | Полное движение `m r̈ = q E_FEM(r,t)` в исходном элементном P2-поле |
| B | Медленное движение `m R̈ = −∇Ψ_FEM(R)`, с полным пространственным содержанием RF-поля |
| C | Медленное движение в ведущем октупольном потенциале `Ψ4 = B6 r⁶` |

Буквы моделей не следует путать с RF-группами электродов A/B/C.
Сравнение A–B проверяет временное усреднение только после контроля
пространственных и численных ошибок. Сравнение B–C проверяет отбрасывание
высших пространственных гармоник. A–C — итоговая проверка всей цепочки.
Квадруполь используется как отдельный эталон, не как замена зависимости r⁶.

## 3. Построить проверенное представление модели B

Базовая формула:

```text
Ψ_FEM(R) = q² (|Ec(R)|² + |Es(R)|²) / (4mΩ²),  Ω = 2πf
```

- [x] На тех же точках сверить её с существующими функциями
  `mean_square_field_from_basis` и `time_average_field_squared`.
- [x] Сохранить полную двумерную зависимость. Не заменять её угловым
  средним или r⁶ до сравнения с моделью C.
- [x] Выбрать способ вычисления ∇Ψ с контролируемой ошибкой. Сырые P2-поля
  имеют скачки на рёбрах; поэлементная производная без учёта скачков
  не задаёт автоматически силу глобального гладкого потенциала.
- [x] Рабочий кандидат: восстанавливать **скалярные RF-квадратуры
  потенциала** гармоническим разложением внутри круга без электродов,
  сохраняя разрешённые высшие гармоники. Получать E и производные
  аналитически. Проверить устойчивость по порядку разложения, радиусам
  подгонки и независимым пространственным контрольным точкам.
- [x] Для гладких квадратур применять согласованную силу
  `F_B = −q²/(2mΩ²) · (Jcᵀ Ec + Jsᵀ Es)`, где `Jij=∂Ei/∂Rj`.
  Проверить её конечными разностями Ψ и сохранением энергии модели B.

Если используется восстановление, ввести вспомогательную полную RF-задачу
`A_smooth` с этим же гладким полем. Тогда:

1. A–A_smooth измеряет влияние восстановления пространственного поля.
2. A_smooth–B проверяет усреднение при строго одинаковом гладком поле.
3. A–B остаётся конечным сравнением с исходным FEM и содержит обе ошибки.

Без этого контроля нельзя называть расхождение A–B чистой ошибкой
усреднения. Если ошибка восстановления велика, нужно улучшить
представление/сетку и зафиксировать, что достоверного вывода пока нет.

Выход: `model_b/` — реализованные Ψ, сила, интегратор, параметры
восстановления и его независимая проверка. Модель B не подгонять

как доказанное динамическое поле нельзя.

## 6. Пилотное сравнение на физически достаточном времени

- [x] Оценить характерный медленный период по модели C, затем уточнить
  по результатам. Сравнивать минимум 3 медленных периода в пилоте;
  для выбранных контрольных случаев расширить до 10 периодов.
  При приближении к центру r⁶-ловушки период растёт: фиксированные
  1000 или 10000 RF-периодов не гарантируют достаточно долгого опыта.
- [x] Запустить A, B, C и при необходимости A_smooth на одном физическом
  интервале с общей временной сеткой для сравнения.
- [x] Для A начать с DOP853 и `max_step ≤ T_RF/50`; далее уменьшить шаг
  минимум вдвое и ужесточить tolerances. Это начальная настройка,
  её достаточность устанавливается по сходимости.
- [x] Сохранять `t,x,y,vx,vy`, медленные координаты, энергию B/C,
  фазу, события выхода из допустимой области и диагностические параметры.
  Проверять успешное завершение интегратора, не только радиус выхода.

Основные метрики для каждой пары:

```text
δ_RMS = sqrt(mean(|R1(t) − R2(t)|²)) / R_scale
δ_max = max(|R1(t) − R2(t)|) / R_scale
```

`R_scale` — заранее зафиксированный масштаб орбиты по начальным данным,
например амплитуда C; он не обращается в нуль при проходе через центр.
Дополнительно: ошибка медленного периода, амплитуды, фазовый сдвиг,
энергетический дрейф B/C и накопление координатной ошибки по времени.
Первичное сравнение проводить без подгонки временного сдвига и масштаба.

Выход: `pilot/` — таблица метрик, XY- и временные графики, журнал
сходимости ODE. Если численная ошибка выше бюджета, сначала исправить
численный расчёт; не делать физического вывода по одному несовпадению.

Для каждого обычного запуска сохранены два уровня ODE. Данные — в `pilot/`,
повторный запуск проверяет подписи и SHA и использует готовые checkpoint.

max=18,7446% (бюджеты 0,1% и 0,3%). На первом оценочном медленном цикле
RMS=2,87e−8 от 1 мм, далее расхождение резко растёт. Причина требует
отдельной проверки; это не доказательство хаоса или отказа усреднения.
Статус этапа: `pilot_computed_raw_FEM_inconclusive`.
Без сходящегося A нельзя утверждать, что метод проверен по исходному FEM.

## 7. Проверить контролируемый высокочастотный предел

- [ ] Выполнить серию `f_s=s f`, `U_s=s U0`, например `s=1,2,4`.
  Геометрия, q/m, медленные начальные условия и физическое время одинаковы.
  Тогда ведущий Ψ не меняется, а микродвижение и η уменьшаются.
- [ ] Ожидать уменьшения ошибки A_smooth–B до численного предела;
  отдельно следить за сеточной ошибкой в A.
- [ ] Не использовать для этой цели подобие `U/f²=const`: оно сохраняет
  относительную силу RF-движения и не является проверкой улучшения усреднения.

Выход: `frequency_limit/` — ошибка против частоты с численной погрешностью.
Это проверка тенденции, не требование идеального степенного закона на
любых трёх точках или строгой монотонности каждого мгновенного отклонения.
