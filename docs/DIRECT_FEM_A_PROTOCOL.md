# Завершение прямой проверки FEM A

Критерии и входные данные фиксируются в
`outputs/abc_validation/direct_fem_validation/v2/validation_settings.json`
до длительных RF-расчётов. Эта работа продолжает прежние проверки;
исторические результаты P2 не переписываются и не объявляются прошедшими.

## Что является A

A — прямое решение полных уравнений Ньютона в RF-поле, вычисленном как
градиент FE-потенциала той же граничной задачи. Для контроля пространственной
ошибки используется P4 на существующих геометрических сетках 50 и 35 мкм.
Геометрия аффинная, граничные многоугольники как в прежних расчётах.
Гармоническое восстановление, сглаживание градиента или подгонка к траектории
в силу A не входят. Точное преобразование локального FE-полинома в степенной
базис — только способ его вычисления.

Ведущий потенциал октуполя имеет степень 4. P2 не может точно представить
его внутри одного треугольника; относительная ошибка его градиента особенно
существенна вблизи нуля истинного поля. P4 содержит этот квартный полином
в локальном пространстве аппроксимации. Это объясняет выбор порядка,
но не заменяет проверку сетки и траекторий: высшие гармоники и погрешность
многоугольной границы остаются.

Геометрия 12 электродов имеет сектор 30°. Вводится комплексная RF-квадратура

```text
H = Phi_A + exp(-2pi*i/3) Phi_B + exp(2pi*i/3) Phi_C,
Phi(x,t) = U0 Im[H(x) exp(i*(Omega*t+phi0))].
H(R30*x) = rho H(x), rho=exp(-2pi*i/3).
```

На одном секторе решается **та же задача Лапласа** с электродом H=1,
внешней границей H=0 и фазовым сопряжением двух радиальных сторон.
Начало координат H=0 следует из rho≠1. Связи DOF представлены матрицей T;
редуцированная вариационная матрица — TᴴKT. Радиальные стороны не заземляются
и не становятся изолирующими границами. Это точная циклическая симметрия
граничной задачи, а не усечение угловых мод.

Для P2 на исходной сетке проверено совпадение с прежним полным FEM:
RMS поля 4,795e−13 относительно полного поля, max абсолютного различия
3,122e−7 В/м. Сводка: `h70_P2/full_P2_equivalence.json`.
Для P4 проверены фактическая ориентация H1 DOF, локальные полиномы,
градиент/Якобиан точного квартного потенциала и весь фазовый закон ABC.
Документация элемента: [scikit-fem](https://scikit-fem.readthedocs.io/en/latest/api.html#module-skfem.element).

## Зафиксированные случаи

q=+1e−12 Кл, m=1e−15 кг, U0=250 В, f=100 кГц, без DC, трения и гравитации.
Исходные полные физические состояния A берутся из прежнего
`initial_conditions.json`, одинаковы на обеих сетках и не корректируются
для получения лучшего совпадения. RF-часы глобальные, фаза общая всем группам.

- Фазы 0 и π/2: 7506 RF-периодов, 0,07506 с, ≈3,25 Ts.
- Фаза 0 дополнительно: 23672 RF-периода, 0,23672 с, ≈10,25 Ts.
- Основной A: геометрически проверяемый DOP853 T/50 и T/100.
- Дополнительный контроль: h35, фаза 0, пилот — DOP853 T/200 и Radau.
- Все сохраняемые плотные полиномы RK проверяются на принадлежность элементу
  через барицентрические полиномы Бернштейна. Переход сохраняет r,v,t.
- Неоднозначное вырожденное продолжение даёт ошибку, а не сдвиг состояния.
- Выходная сетка — 64 интервала на RF-период.

Физические допуски прежние: RMS координат 1%, max 3%, период 1%.
Численный/пространственный бюджет: RMS 0,1%, max 0,3%, период 0,1%.
R_scale=1 мм, без фазового совмещения или подгонки временного сдвига.

При недостаточной сходимости требуется дополнительное уточнение;
неудачная численная проверка не заменяется физическим вердиктом.

## Разделение ошибок

1. Контроль A по шагам/методам, контроль сетки h50→h35.
2. Сравнение A с исходными замороженными B70/C70.
3. B и C заново вычисляются по прямому P4 FEM каждой сетки; C4 берётся
   из Fourier n=4 прямого потенциала, а не из подгонки движения.
4. Диагностический A_fit строится по N48 того же P4-скалярного потенциала,
   с тем же полным состоянием. Он нужен для измерения влияния восстановления.
   Основной A его не использует. A_fit имеет один временной уровень;
   точность A контролируется отдельно несколькими методами/шагами.
5. Влияние исходной карты микродвижения при изменении FEM оценивается
   отдельно быстрым расчётом B из восстановленного медленного старта.
6. Проверяются периодный фильтр, 32/64 отсчёта, окна 1/2/3 периода,
   альтернативный RF-тренд и обратное преобразование микродвижения.

Первичная координата RF — центрированное среднее за RF-период.
Периоды извлекаются одинаково для всех моделей, без сдвига фаз.

Готовые checkpoint проверяются по SHA. Для extended нужен matching pilot
той же сетки/фазы/уровня. В продолжении сохраняется глобальное время.
Новые FE-решения, исходники и диагностика — в `h*_P*/`; траектории — в `runs/`.
Итоговые научные статусы назначаются только после анализа всех контролей.

Расчёт и анализ завершены: [результаты и контекст](DIRECT_FEM_A_RESULTS.md).


## Поправка к геометрическому контролю v2

v1 сохранена отдельно: все прямые пилоты h35 остановились на строгом
контроле границы. Локальный повтор показал барицентрический остаток соседнего
треугольника −6,092e−14 при допуске 256 eps = 5,684e−14. Преобразование
локального корня в глобальное float64-время имеет конечную точность.
В v2 добавляется оценка перемещения от восьми ULP глобальных часов:

```text
tau(clock,state) = 256 eps + 8 ulp(clock) |v| max_cells,faces |grad(lambda)|.
```

Этот допуск используется в геометрическом контроле и выборе следующего
элемента; времена, координаты и скорости не сдвигаются. Максимальный допуск
и его оценка в метрах записываются в метаданные каждого нового запуска.
Выполненные v1-пилоты h50 и диагностические A_fit повторно используются
с прежними байтами, отдельной записью `reused_from_v1` и хешами исходного
численного ядра: они уже прошли более строгий геометрический контроль.
Сила, геометрия, физические состояния и настройки ODE у этих случаев те же.
Источники FE-полей остаются в v1; v2 содержит копии неизменных FE-артефактов
и новые RF-проверки. Исторические P2-данные также не меняются.
