# Код и выбранные данные на GitHub

Обновлено 28.10.2026. По просьбе пользователя публикация сокращена:
крупные промежуточные массивы остаются на исходном компьютере.
Полный список исключений с путями, размерами и SHA-256 приведён в
[LOCAL_ONLY_DATA.md](LOCAL_ONLY_DATA.md).

## Что опубликовано

- Весь код, конфигурации, тесты, снимки исходников и отчёты.
- Ранее опубликованные численные массивы без изменений; общий
  `outputs/abc_validation/progress.json` дополнен результатами новых этапов.
- Сетки Gmsh 35/50/70 мкм, включая сектор и полную геометрию.
- Поля P4 `sector_solution.npz` и `common_samples.npz` для h35/h50
  в `outputs/abc_validation/direct_fem_validation/v2/`.
- Медленные координаты A за 50 Ts (`slow_samples.npz`), кривые сравнения
  (`analysis/v1/comparison_curves.npz`) и опорные `B35_fine.npz`, `C35_fine.npz`.
- Таблицы, рисунки, настройки, метаданные, исходные статусы и контрольные суммы
  исследований, включая неудачные диагностические версии.

Новый научный набор содержит 493 файла, 108 127 068 байт (103,12 МиБ),
помимо уже опубликованных данных. Для него Git LFS не требуется.
Непосланный упаковочный коммит с LFS заменён до публикации; ранее
опубликованная история не переписывается.

## Загрузка и проверка

```powershell
git clone https://github.com/snejokzboxik/three-phase-12-electrode-trap.git
Set-Location three-phase-12-electrode-trap
python scripts/verify_repository_data.py
```

Для существующего клона: `git pull`, затем та же команда проверки.
Ожидается `status: passed`, `scope: published_subset`,
`intentionally_omitted_files: 217`. Проверка использует только стандартную
библиотеку Python, ничего не пересчитывает и не меняет научные данные.

`outputs/REPOSITORY_DATA_MANIFEST.json` сохраняет реестр всех 1139 файлов
исходного локального набора (4 874 928 069 байт). У каждого файла есть
`availability`: `github` или `local_only`, размер и SHA-256.
На исходном компьютере можно проверить также все исключённые массивы:

```powershell
python scripts/verify_repository_data.py --full-local
```

## Ограничения воспроизведения

На новом клоне можно читать отчёты и работать с выбранными полями и кривыми.
Повторный полный анализ прямого A и проверка всех checkpoint требуют
исключённых входов; `--verify-artifacts` отдельных исследований может
закономерно сообщить об их отсутствии. `git pull` эти файлы не восстановит:
нужна копия с исходного компьютера либо новый расчёт с предусмотренной
проверкой происхождения данных. Сохраняемые `manifest.json` и `COMPLETED.json`
описывают исходный расчёт и сами по себе не означают наличие всех его файлов
в опубликованном наборе. Выборочные кривые не заменяют полный RF-архив.

Контекст: [прямая проверка A](DIRECT_FEM_A_RESULTS.md),
[анализ 50 Ts](LONG_A_50_RESULTS.md), [запуск с нуля](RUN_A_50_PERIODS.md).
Глобальная сходимость A на 50 Ts остаётся непроверенной; публикация данных
не меняет научные выводы и статусы. Статья вне папки Git-репозитория в набор
не входит. Кэши Python/pytest и виртуальные окружения также исключены.

После добавления новых данных реестр можно осознанно обновить командой
`python scripts/verify_repository_data.py --write-manifest`.
Она учитывает известные локальные исключения; это не заменяет внутренних
контрольных сумм отдельных исследований. При намеренной публикации
исключённого файла нужно также убрать его точное правило из `.gitignore`
и обновить список в `LOCAL_ONLY_DATA.md`.
