## Воспроизведение

В корне проекта, с установленными зависимостями из `pyproject.toml`.

```powershell
python -B -m pytest -p no:cacheprovider -q
python -B scripts/run_effective_reconstruction_v1.py --out outputs/effective_reconstruction/replay_v1
python -B scripts/plot_effective_reconstruction_v1.py outputs/effective_reconstruction/replay_v1
Push-Location outputs/effective_reconstruction/replay_v1
xelatex -interaction=nonstopmode -halt-on-error ../../../docs/EFFECTIVE_RECONSTRUCTION_V1.tex
xelatex -interaction=nonstopmode -halt-on-error ../../../docs/EFFECTIVE_RECONSTRUCTION_V1.tex
Pop-Location
```

Выходная папка должна отсутствовать до запуска. Для отдельного контроля C укажите `--stage synthetic` и отдельную папку. Полный расчёт v1 занимает несколько минут, включая два шага чистого аналитического RF-контроля. Исходные P4-массивы читаются по ссылкам из `input_sha256.json`, включая хеши журналов переходов и родительских checkpoint. Для сборки PDF нужны XeLaTeX и шрифты Times New Roman, Arial, Consolas.

## Состав результатов

- `configuration.json`, `input_sha256.json`, `result_sha256.json` фиксируют протокол, входы и численные результаты. `delivery_sha256.json` включает графики, PDF и исходники исследования.
- `synthetic.csv`, `synthetic_fit.json`, `C_*mm.npz` содержат периоды, амплитуды, контроль энергии и отложенные амплитуды.
- `frozen_models.json` записан до чтения отложенного FEM-запуска. В D подогнан только коэффициент при заранее фиксированном (p=6). E использует калибровку поля и выведенный скоростной член, без оценки параметров из траекторий.
- `slow_diagnostics.csv` содержит развороты и сводку оценок по четырём фильтрам. Для сырого строба в аналитическом контроле используется ближайшая доступная фиксированная RF-фаза.
- `comparisons.csv` содержит векторные, радиальные, поперечные, временные и угловые метрики на общем физическом времени. `waveform_spectrum.csv` содержит отношения гармоник за один полный цикл. Спектральная проекция не изменяет часы сравнения траекторий.
- `velocity_pair.csv` и `velocity_pair_*.npz` содержат прямой тест нечётности ускорения. `oct*_RF.npz` содержат исходные состояния полных аналитических RF-запусков с шагом интегратора до (T_{mathrm{RF}}/20) на выходных узлах через (T_{mathrm{RF}}/16).
- NPZ в единицах СИ. `states_SI` хранит (x,y) либо (x,y,v_x,v_y). `turning_points` хранит (t,x,y,r,	heta_mathrm{line}), угол в радианах. В сравнительных файлах `RF_mean_m` — координаты A или аналитического RF, ключи B/C/D/E — состояния эффективных моделей.
- Три PNG показывают [потенциал](potential.png), [P4-траектории](trajectories.png) и [аналитический RF-контроль](analytic_control.png).

Полный набор тестов при расчёте v1 — 105 прошедших тестов, включая 5 новых проверок обратной задачи, энергии, размерностей и разделения запусков.
