# Численные проверки V11 — текущий объём

- Независимое поле C решено P4 FEM на h50 и h35 с анти-периодическим условием при повороте на 30°. Удержан ведущий порядок `m=6`; прямой контроль антисимметрии потенциала дал максимальную невязку `4.86×10⁻¹⁷ V` на единичном возбуждении для трёх тестовых точек.
- Диагностическая N48-реконструкция C по независимым от fit точкам имеет относительный RMS поля `1.038×10⁻⁷` на h35/h50. Ведущий коэффициент `m=6` различается между сетками на `5.47×10⁻⁵` относительно.
- В первой карте 915/915 траекторий имеют численно завершённый статус, 305/305 координат имеют A/B/C, все выходы лежат внутри заданного времени и заканчиваются на апертуре.
- 48 h35 N48 повторов на 16 краевых координатах дают 48/48 совпадающих бинарных исходов с h50 N48; максимальное различие времени выхода по 36 выходам `0.000974 RF`.
- Для C прямое интегрирование нативного P4 FEM градиента со строгим контролем переходов между элементами дало `25.5692927 RF` на h50 и `25.5693877 RF` на h35 для `(x0,y0)=(3.75,−6) mm`, `v0=0`, `φ=0°`, `U=250 V`. h50 N48: `25.5693120 RF`.
- Архивный `tests/test_direct_fem.py`: 10 тестов прошли. Исходный модуль прямого FEM V10 оставлен неизменным.

Остаётся: строгий DOP853 на чувствительных точках, прямой P4 для других краевых исходов, контроль больших горизонтов, сравнение площадей на 61×61 и независимые карты фаз/нормировки. Смена исхода между h35 и h50 должна получать метку «пространственно неразрешён».
