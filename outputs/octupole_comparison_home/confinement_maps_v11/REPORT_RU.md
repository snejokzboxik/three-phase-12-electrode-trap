Исходный `master`: `e47b30ff90a3897236cea737a085ca9d22ee4020`, совпадал с `origin/master` на момент проверки. Первый этап V11 сохранён коммитом `1105747` и запушен в `master`. Физическая постановка: `100000 Th`, `+e`, `100 kHz`, апертура `8 mm`, поперечная RF-динамика без диссипации. Удержание означает лишь отсутствие первого наружного пересечения апертуры до указанного конечного времени.

## Независимое поле C

Трёхфазный A/B FEM-базис содержит только суммы по классам электродов `i mod 3` и не даёт чередующегося вектора `(+1,-1,...)`. Для C решена новая P4 задача на существующих геометрических сетках h50 и h35: электрод сектора `+1 V`, внешняя граница `0 V`, швы `Φ(R30° x)=-Φ(x)`. При повороте двенадцати секторов это даёт физическое питание соседних электродов `+ − + − ...`. Это FEM-решение, а не идеальное аналитическое поле `m=6`.

| Сетка | Ведущий коэффициент `m=6` при `r=8 mm`, В/В | `m=18`, В/В | RMS потенциала / поля N48 на независимых точках |
|---|---:|---:|---:|
| h35 P4 | 0.676021107 | 0.009794009 | 1.155×10⁻⁸ / 1.038×10⁻⁷ |
| h50 P4 | 0.675984098 | 0.009794827 | 1.155×10⁻⁸ / 1.038×10⁻⁷ |

Относительное различие коэффициента `m=6` между сетками — `5.47×10⁻⁵`. Для h35 дискретный масштабированный остаток FEM — `8.16×10⁻¹⁶`; найдено 1445 совпадающих пар DOF на швах с максимальной геометрической невязкой `8.78×10⁻¹⁵ m`. Диагностическая N48-реконструкция используется для массовых траекторий; ключевые границы требуют прямой P4 проверки.

## Нормировка

Протокол равных пиков: `A=B=C=250 V`. Для согласованного протокола `A=250 V`, `B=353.553390593 V`. Напряжение C выбирается из равенства углового среднего `⟨|E_cos|²+|E_sin|²⟩` с A на фиксированном радиусе. На h50: `3020.08 V` при 2 мм, `755.66 V` при 4 мм, `342.78 V` при 6 мм. Это сильная зависимость от радиуса, ожидаемая при сравнении ведущих порядков `m=4` и `m=6`; единое ранжирование схем из одного радиуса недопустимо.

## Пилот и очередь

Реализованы `scripts/build_v11_antiphase.py` и `scripts/run_v11_xy.py`. XY-сетка 21×21 содержит 305 физических координат внутри круга `r<7.5 mm`, по 3 модели, всего 915 заданий на фазу и протокол. Вне этой области классы не заполняются интерполяцией. Каждое задание сохраняет атомарные сегментные checkpoint JSON и различает `retained`, `escaped`, `numerical_error`.

Проверка 3 совпадающих стартов до 10 RF (фаза 0°, 250 В) заняла 2.8 с суммарного времени 3 рабочих процессов вместе с запуском. На выбранной близкой к краю точке `(−3,−6.75) mm` B вышла за 1.5316 RF, C за 8.8642 RF, A не вышла до 10 RF. Этот пилот нужен для проверки конвейера и стоимости, не является сравнением площадей удержания.

Первая полная карта h50 N48, 250/250/250 В, фаза 0°, 1000 RF завершена: 915 траекторий для 305 координат, 3639 с при четырёх процессах. Все точки имеют по три сопоставимых записи, численных ошибок нет. У каждого зарегистрированного выхода время находится внутри `(0,1000)` RF, а конечный радиус совпадает с 8 мм в пределах `10⁻⁸ m`. Данные и промежуточные сегменты: `xy/4ceec3a67c8fdfcd/`.

Для переноса через Git 7937 сегментных checkpoint JSON упакованы в `checkpoints_v11.zip` (3,669,684 байт; SHA-256 `d8b021e1924eb781c0925d739942bb07c45a09d1fac378254a143bedaac139c6`). Распакованные файлы остаются локально. После свежего клонирования архив можно извлечь в корень `confinement_maps_v11/`, и тот же расчёт продолжит работу по сохранённым сегментам.

Клеточная оценка площади с шагом `0.75 mm` равна `169.31`, `90.56`, `162.56 mm²` для A/B/C соответственно. Это сумма площадей удержанных ячеек, включая краевые ячейки выборки; погрешность разрешения сетки ещё не установлена. На этой сетке B не имеет преимущества над A или C, но при других фазах, скоростях, горизонтах и нормировке такой вывод пока не проверен. Визуально B проявляет выраженную азимутальную границу, A и C имеют в основном удержанные внутренние точки. Отдельные краевые пиксели не объявляются островами до адаптивного уточнения и FEM-проверки. Сохранённый `sampled_max_radius_m` основан на одном стробоскопическом отсчёте за период и может занижать максимум внутри периода.

Все 16 координат, где A или C вышла на h50, пересчитаны на h35 для всех трёх схем: 48/48 бинарных исходов совпали. Среди 36 вышедших повторов максимальный сдвиг времени выхода составил `0.000974 RF`. Это выборочный контроль краевых точек, не сертификат сходимости всей 305-точечной карты. Для C отдельно выполнен прямой P4 расчёт старта `(3.75, −6) mm`, `v=0`: время выхода `25.5692927 RF` на h50 и `25.5693877 RF` на h35 против `25.5693120 RF` у h50 N48. Таким образом, этот ранний выход сохраняется без гармонической аппроксимации. Остальные отдельные краевые пиксели требуют прямого P4 и более строгого интегратора перед утверждениями об их тонкой структуре.
