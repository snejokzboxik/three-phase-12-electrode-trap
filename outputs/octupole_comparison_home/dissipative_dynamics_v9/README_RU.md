# V9: разведочный пилот диссипативной динамики

Расчёты используют только сохранённые h50/h35 N48-поля из FEM-derived наборов. Новые FEM-решения не создаются. Основной протокол — согласованный ведущий псевдопотенциал, 250 В для вращающейся модели и 353,553390593 В для стоячей, DOP853 и апертура 8 мм.

`run_v9.py --stage sweep` возобновляет checkpoint-запуски. `--stage h35-check` повторно сопоставляет четырёхточечные γ=0 результаты с V6/V8. `--stage lyapunov` рассчитывает полный четырёхмерный касательный спектр после заданного переходного участка для одного старта. `render_v9_figures.py` строит компактные многопанельные рисунки в sans-serif стиле, PDF/SVG и PNG 600 dpi. `validate_v9.py` проверяет балансы энергии, знаки трения, правое цензурирование и сумму показателей.

Основной набор содержит полную серию γ=0, 10, 100, 1000, 3000 с⁻¹ для глубокого старта и сбалансированные точки γ=0, 100, 1000, 3000 с⁻¹ для трёх остальных стартов. Эта разреженная схема выбрана для проверки режима и влияния трения за ограниченный бюджет; она не является картой бифуркаций.
