# V5: согласованная ведущая псевдопотенциальная сила

Этот каталог содержит отдельный от V4 сбалансированный тест: вращающаяся модель при 250 В сопоставлена со стоячей при 353,553390593 В. Ровно согласован ведущий псевдопотенциальный масштаб при опорном радиусе 0,5 мм. Полные эффективные потенциалы при этом не предполагаются одинаковыми.

Основной набор — 192 парных начальных состояния на 1, 2 и 3 эВ. Вращающиеся траектории повторно использованы из V4 после проверки состояния, знака скорости и решателя; 192 стоячие траектории рассчитаны здесь. Все интеграции записывают периодические контрольные точки и траектории.

См. [научный отчёт](REPORT_RU.md), [конфигурацию](study_config_v5.json) и [проверку данных](processed/numerical_verification_v5.json).

Пересборка: `python run_matched_strength_v5.py --prepare-only` (проверка и создание стартовой сетки), `python render_matched_strength_figures.py` (рисунки), `python validate_matched_strength_v5.py` (численная и файловая проверка). Повторный запуск интегратора использует завершённый append-only журнал и не повторяет готовые траектории.
