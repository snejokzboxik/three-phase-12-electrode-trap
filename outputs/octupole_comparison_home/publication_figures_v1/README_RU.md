# Публикационные рисунки V4

Это переоформленные графики опубликованного V4. Сценарий использует исходные V4 CSV и сохранённые траектории; RF-интеграции и FEM-пересчёты не запускаются. Исходные рисунки V3/V4 не изменяются.

## Состав

Четыре рисунка экспортированы для одноколоночной ширины 89 мм и двухколоночной ширины 178 мм. Каждый вариант имеет векторные PDF и SVG, а также PNG с разрешением 600 dpi.

1. `Fig1_energy_finite_time_confinement`: конечновременное удержание по энергетическим оболочкам для вращающегося и стоячего поля и их парная разность. Все 11 рассчитанных оболочек показаны без соединяющих линий; круги отмечают сбалансированные оболочки 1, 2 и 3 эВ, квадраты — адаптивные энергетические точки. Внизу указано число matched начальных условий на каждой оболочке.
2. `Fig2_balanced_phase_azimuth_pairs`: классы парного исхода на сбалансированной сетке, отдельно по энергии и начальному радиусу. Адаптивные точки не смешаны с этой сеткой. Для различения знака касательной скорости маркеры смещены по вертикали на ±1,4° только на рисунке.
3. `Fig3_matched_trajectories_and_radius`: проверенная пара траекторий, где вращающееся поле переживает 1000 периодов, а стоячее достигает апертуры на 21,31 RF. Показаны геометрия x–y и радиус во времени; ранний интервал увеличен отдельной панелью.
4. `Fig4_first_passage_and_orbital_differences`: времена первого выхода и парные разности максимального и RMS-радиуса. Сохранившиеся траектории показаны как правоцензурированные выше 1000 RF, а не как события выхода. Небольшой горизонтальный jitter служит только для разделения близких меток; исходные энергии не меняются.

Все доли и разности описывают конкретную детерминированную сетку V4 и не трактуются как статистическая вероятность для популяции. Непрерывная граница удержания не интерполируется.

## Воспроизведение и проверки

При наличии Python 3.12, Pillow, ReportLab и шрифтов Cambria в Windows выполните из корня репозитория:

```powershell
python outputs/octupole_comparison_home/publication_figures_v1/render_publication_figures.py
```

Проверки в сценарии подтверждают 522 полные пары, совпадение физических начальных состояний, горизонт 1000 RF, корректную маркировку цензурирования и наличие 64 matched запусков на каждой из трёх сбалансированных энергий. SHA-256 двух исходных V4 таблиц сохранены в `figure_data_audit.json`.

Matplotlib отсутствовал в используемом Python, а доступ к индексу пакетов был недоступен. Поэтому применён локальный векторный рендерер на Pillow/ReportLab, без добавления сторонней зависимости в исходные данные V4. Пересчёт значений не выполняется.
