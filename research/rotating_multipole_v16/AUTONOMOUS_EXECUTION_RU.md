# Длительный запуск и ограничения среды

## Возобновляемость данных

Каждый ансамбль завершается отдельной задачей. Перед checkpoint строка результата с SHA-256 сбрасывается на диск, затем атомарно обновляется `results/checkpoint.json`; `results/progress.json` показывает текущую задачу. При старте runner проверяет хеши записей, восстанавливает готовые task ID и пропускает их. Внутри текущего короткого ансамбля может повториться максимум незавершённый блок; уже записанные задачи не теряются.

## Проверка отделения от управляющей команды

В текущем Windows managed sandbox независимый launcher не поддержан:

- `Start-Process` создал процесс, но дочерний процесс был завершён после окончания управляющей команды;
- регистрация через PowerShell Task Scheduler упёрлась в недоступный CIM endpoint;
- `schtasks.exe /Create` ответил `The network address is invalid`;
- Win32 `CREATE_BREAKAWAY_FROM_JOB` отклонён с `WinError 5 / Access denied`.

Поэтому заявлять, что расчёт гарантированно продолжится после закрытия Codex, нельзя. Runner запущен в управляемой долгоживущей командной сессии, доступной для контроля через tool-session. Если она будет прервана, возобновить так:

```powershell
cd C:\Users\snejochek\Documents\ChatGPT\12electrodes\rotating_multipole_v16
python -u scripts/run_search.py --hours 10
```

Основная очередь этого запуска завершена: `results/progress.json` содержит `QUEUE_COMPLETE`, `completed_count=382`; строки результата проверяются по SHA-256. Дополнительные экраны гармоник и QR также завершены. Во время QR-прогона Windows один раз отказала заменить checkpoint при одновременном чтении: перезапуск восстановился из полностью записанного временного файла на RF 7850. В `lyapunov_extension.py` добавлен повтор атомарной замены при краткой блокировке; сценарий восстановления учитывает и основной, и временный checkpoint. Все runner-ы сейчас завершены.
