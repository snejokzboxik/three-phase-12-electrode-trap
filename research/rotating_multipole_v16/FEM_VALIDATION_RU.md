# Проверка FEM-поля — статус

Поле FEM в динамику пока не импортировалось. Проверен только лёгкий список GitHub для `snejokzboxik/three-phase-12-electrode-trap`; размер репозитория в API — `2,847,536 KiB`, поэтому полный clone не делался.

В доступной ветви есть сетки `outputs/meshes/gmsh_35um/trap.msh` (24,746,409 B) и `gmsh_50um/trap.msh` (12,258,729 B), а также метаданные FEM-вариантов:

- h35, `outputs/fem_cache/variants/4169ae3c40d920944fc1/metadata.json`, expected `p2_basis.npz` SHA-256 `9020502649750e86fa1b85639b1995ddf76743af5991d4b463b26de902e8173f`, 1,299,121 P2 DoF;
- h50, `outputs/fem_cache/variants/915052d897401e5b84c6/metadata.json`, expected SHA-256 `a432a439d5b0d02cdc6547a96d002a7c2fac63059e06b435562df7576b84ca49`, 642,841 P2 DoF.

В этих двух variant-директориях GitHub показывает только `metadata.json`, не FEM-массивы. Обнаруженный общий `outputs/fem_cache/p2_basis.npz` (29,0 MB) относится к другой сетке, h70 (`mesh_file=outputs/meshes/gmsh_70um/trap.msh`), и не подменяет h50/h35. Их метаданные задают четыре 1-V базиса A/B/C/DC; потребуются точные фазы/комбинации старого проекта для реконструкции m=4 и m=2.

Для передачи достаточно добавить в доступное хранилище недостающие два `p2_basis.npz` (или воспроизводимый solver snapshot вместе с точными lock-файлом и командами для их построения). Из-за доступной RAM около 3 GiB повторный P2-расчёт на 642k и 1.3M степеней свободы на этой машине не запускался. FEM-валидация `NOT_RUN`; аналитическая гармоника не выдаётся за FEM.

В качестве ограниченной проверки чувствительности, а не замены FEM, введены со-вращающиеся члены `Vm=kappa_m*Re[z^m exp(-i*((m/4)*tau-delta_m))]` для `m=8,10`. Они удовлетворяют двумерному уравнению Лапласа, а их совместная частота с основной гармоникой имеет период 2 RF.

Проведено 42 сопоставимых ансамбля: `kappa4=0.1044`, `N=64`, горизонт 300 RF, два независимых scrambled Sobol-набора; `|kappa8/kappa4|=0.03,0.1,0.3`, `|kappa10/kappa4|=0.1,0.3`, четыре относительные фазы. Две базовые доли выживших равны `10/64` и `8/64`. По выбранным амплитудам фазовые средние для m=8 лежат в диапазоне `0.127–0.131`, для m=10 — `0.133–0.135`, против среднего базиса `0.141`. Ни в одной фазо-амплитудной группе не было добавившихся выживших относительно совпадающего базового набора; число потерянных менялось от нуля до менее одного старта в среднем на фазу и seed. Устойчивого монотонного тренда по амплитуде не обнаружено.

Для `epsilon=0.3`, `delta=pi/2` выполнено удвоение шага с 96 до 192 шагов/RF (12 расчётов, включая базу, два поля и два seed). Базовая и возмущённая маски разошлись на один старт для seed 6128 и совпали для seed 16128. При 192 шагах m=8 потерял один базовый старт в первом seed; m=10 в первом seed потерял один и приобрёл один, сохранив общее число; оба возмущения совпали с базой во втором seed. Следовательно, эффекты на уровне одного старта сопоставимы с шаговой чувствительностью этого скрининга.

Амплитуды и относительные фазы гармоник не измерены в реальном поле и не подогнаны к FEM. Эти расчёты показывают только слабую/неразрешённую чувствительность выбранной области начальных условий к сценарным высшим гармоникам; они не реконструируют h50/h35 и не подтверждают физическую модель.
