# V16 — нелинейная динамика вращающегося мультиполя

Самостоятельный минимальный вычислительный пакет для моделей, заданных в приложенном V16-задании. Все координаты безразмерны: `x=X/R`, `tau=Omega*t`, а потенциал `V=Q Phi/(M Omega^2 R^2)`. Результаты поиска пишутся в `results/` по мере выполнения.

Снимок 18.11.2026: основная возобновляемая очередь завершена — 382 проверенные по SHA-256 задачи; создано 12 высокоточных подтверждений до 1000 RF. Дополнительно завершены 42 ансамбля чувствительности к гармоникам `m=8,10`, шаговая проверка сильнейших возмущений и QR-продолжение одного кандидата до 10 000 RF. Итоговые результаты: `results/lyapunov_10000rf.json` и `figures/lyapunov_10000rf.png`.

## Требования и запуск

Проверенная среда: Windows 11, Python 3.12.10, NumPy, SciPy, Matplotlib; 12 логических CPU, 16 GiB RAM, около 3 GiB доступной RAM при аудите. Код ограничивает ансамбли и использует один вычислительный процесс.

```powershell
python -m pytest
python scripts/validate_core.py
python scripts/run_search.py --hours 10
```

Для локального Windows-сеанса вне управляемого sandbox Codex можно запустить скрытый дочерний процесс:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_background.ps1
```

В текущем управляемом окружении независимый дочерний процесс проверить не удалось: `Start-Process`-процессы завершались вместе с управляющей командой, регистрация в Task Scheduler недоступна, а Windows запретила breakaway-процесс. Здесь runner запускается как длительная управляемая командная сессия. Есть блокировка от второго активного экземпляра; каждая строка результата сбрасывается на диск с SHA-256, checkpoint записывается атомарно. После прерывания повторный запуск пропускает готовые ID задач. Подробности и команда возобновления — в [AUTONOMOUS_EXECUTION_RU.md](AUTONOMOUS_EXECUTION_RU.md). Смотрите `results/runner.log`, `results/progress.json` и `results/search_results.jsonl`.

## Границы текущей модели

Модели A–D, двумерная жёсткая заряженная палочка, вращающаяся система отсчёта, интегратор RK4 для ансамблей и DOP853 для контрольных орбит включены. Палочка не является полноценной трёхмерной частицей. Отсутствующие FEM-данные нельзя заменять ведущей гармоникой. Конечное удержание не считается устойчивостью, а конечновременные показатели Ляпунова — доказательством хаоса. Статус каждого исследовательского блока хранится в `MANIFEST.json`.
