# Нелинейные бассейны и бифуркационные границы

## Проверенные линейные ветви

Для RO `kappa4=0.1044`, `ell=0.2`, `gamma_rot=0.004`, `gamma_trans=0.05` точная синхронная ветвь имеет полный 6D спектр внутри единичного круга. Для SO при `gamma_rot=0.003` стрельба нашла для каждого среднего направления `±1/4` устойчивую периодическую ветвь и соседнюю неустойчивую. Устойчивый SO-максимум мультипликатора `0.995149`, неустойчивый — `2.17609`. Невязки замыкания ниже `9e-15`. Поэтому у обоих направлений SO есть конечная локальная область притяжения, хотя она может быть узкой.

## Независимые вращательные ансамбли

Для сравнения RO и SO использованы два независимых scrambled Sobol-набора (`seed=1701, 4813`, по 256 стартов каждый), равномерные начальные `psi∈[0,pi)`, `spin∈[-0.8,0.8]` и RF-фаза `∈[0,2pi)`. Горизонт — `1000 RF`, шаг RK4 — `128` точек/RF. Синхронизация классифицировалась по среднему спину за последние 30 RF с допуском `0.015` вокруг `±1/4`.

| Поле | Захват | Доля | 95% Wilson-интервал |
|---|---:|---:|---:|
| RO | `+1/4`: `40/512` | `7.8%` | `5.8–10.5%` |
| SO | `+1/4`: `19/512` | `3.7%` | `2.4–5.7%` |
| SO | `-1/4`: `16/512` | `3.1%` | `1.9–5.0%` |
| SO | оба направления | `35/512` | `6.8%` (`5.0–9.4%`) |

Обе стороны в SO действительно захватываются при симметричном по направлению ансамбле. В пределах этой выборки суммарная доля захвата SO и RO сопоставима; интервалы перекрываются, поэтому превосходство одного поля по размеру бассейна не утверждается. В SO большая часть стартов пришла к либрации, а не к вращению.

## Полные 6D возмущения и апертура

Дополнительно для каждой модели взяты два независимых ансамбля по 64 старта: COM равномерно в диске радиуса `0.15R`, компоненты начальной скорости `[-0.02,0.02]`, `psi∈[0,pi)`, `spin∈[-0.8,0.8]`, RF-фаза равномерна. Условие нахождения всего стержня внутри апертуры проверялось консервативно как `|Z|+ell/2<1`; вышедшие старты прекращали интегрироваться. Горизонт — `1000 RF`.

- RO: `2/128` захвачены в `+1/4`; ни один старт не вышел за апертуру. Для двух захватов зарегистрированные времена первого устойчивого распознавания — `131` и `232 RF` (медиана `181.5 RF`).
- SO: `5/128` захвачены: `1` в `+1/4`, `4` в `-1/4`; `78/128` пришли к либрации, остальные `45/128` остались в категории `other`; ни один старт не вышел за апертуру. Единственный захват `+1/4` произошёл на `205 RF`; четыре захвата `-1/4` — на `147`, `190`, `207` и `231 RF` (медиана `198.5 RF`).
- Максимальный радиус COM по всем ансамблям — `<0.40R`.

Это небольшой, distribution-specific sample, показывающий узкие глобальные бассейны при широком диапазоне начального спина и ненулевых COM-возмущениях. Он не опровергает локальную линейную устойчивость и не оценивает экспериментальную вероятность без физической подготовки частицы. Время захвата определяется по первому стробоскопическому 30-RF окну, удовлетворяющему фазовым и спиновым критериям пять RF подряд; при таком малом числе успехов медианы имеют большую выборочную неопределённость.

Доли захвата и 95% Wilson-интервалы показаны в [`basin_capture_fractions.png`](figures/basin_capture_fractions.png); исходные количества и времена захвата находятся в `results/basin_rotational.json`.

Временное уточнение угловой части для тех же 64 стартов с `128` и `256` шагами/RF дало совпадение **индивидуальной классификации каждого старта** для RO и SO. Полная 6D выборка выполнена с 128 шагами/RF; её классификации поэтому имеют более слабую гарантию сходимости.

## Бифуркации и границы

1. **RO угловая sync-ветвь.** Уравнение баланса момента даёт две фазы при `gamma_rot<gamma_rot,c`, которые сливаются при `gamma_rot=gamma_rot,c`, где `K=0`. Это аналитический saddle-node фиксированных фаз в сопутствующем кадре. Ниже порога устойчива одна ветвь, вторая неустойчива.
2. **RO COM.** При `2|b|=w sqrt(w²+gamma_trans²)` у COM-полинома появляется нулевой корень. Мы подтверждаем границу по собственным значениям; тип нелинейной потери симметричного центрального равновесия не объявляется pitchfork без продолжения нелинейных стационарных ветвей.
3. **SO.** Устойчивые и неустойчивые периодические lock-решения обнаружены методом стрельбы, но продолжение ветвей по `gamma_rot` и точное место/тип их слияния ещё не выполнены. Численное визуальное изменение траектории не используется для назначения типа бифуркации.
4. **QSO/QRO.** Проверены одиночные контрольные режимы и их Floquet-спектры, но hysteresis-диаграмма и границы удержания не продолжались.

Для RO точные аналитические границы продолжены на три симметричных зарядовых профиля при одном механическом стержне. Сдвиг RF-фазы и знак вращения проверены: меняется фаза фиксированной точки, но линейный спектр инвариантен. Полный adaptive trajectory-scan по независимым `kappa4`, `ell`, произвольным `mu2,mu4` и параметрам SO/QSO/QRO пока не запущен; неаналитические ветви стоячего и комбинированных полей остаются непроанализированными, а не интерполированными из одной точки.
