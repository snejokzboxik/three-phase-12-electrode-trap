# Мультипольное разложение жёсткого стержня

## Нормировка и зарядовые моменты

Используется нормировка V16: `Z=(X+iY)/R=x+iy`, `s=S/R`, `ell=L/R`, `tau=Omega*t`; зарядовые веса нормированы на полный заряд `Q`. Введены закреплённые в теле моменты

\[
\mu_n=\langle s^n\rangle=Q^{-1}\int s^n\,dq.
\]

Это сырые моменты вдоль оси стержня; они не совпадают с декартовым тензором квадруполя без преобразования соглашений. Для центрированного симметричного профиля `mu_1=mu_3=0`. Для равномерного линейного заряда `mu_2=ell^2/12`, `mu_4=ell^4/80`.

## Общая формула

Пусть гармоника порядка `m` имеет комплексную амплитуду `a(t)`. Для распределённого заряда стержня

\[
P_m(Z,\psi)=\langle (Z+s e^{i\psi})^m\rangle
 =\sum_{j=0}^{m}{m\choose j}\mu_j Z^{m-j}e^{ij\psi},
\qquad U_m=\operatorname{Re}[a(t)P_m].
\]

Для бегущей (вращающейся) гармоники `a(t)=kappa_m exp[-i(omega_m tau-delta_m)]`. Для стоячей гармоники `a(t)=kappa_m cos(omega_m tau-delta_m)`.

Положив `P_x=partial P/partial Z` как обычную производную полинома по `Z`, получаем точные производные

\[
U_x=\operatorname{Re}(aP_x),\quad U_y=\operatorname{Re}(iaP_x),\quad
U_\psi=\operatorname{Re}(aP_\psi),\quad
F_x=-U_x,\ F_y=-U_y,\ N_z=-U_\psi,
\]

\[
P_\psi=i\sum_j j{m\choose j}\mu_j Z^{m-j}e^{ij\psi},\quad
P_{xx}=P_{ZZ},\ P_{xy}=iP_{ZZ},\ P_{yy}=-P_{ZZ},\quad
P_{x\psi}=\partial_ZP_\psi,\ P_{y\psi}=iP_{x\psi},\ P_{\psi\psi}=-\sum_j j^2{m\choose j}\mu_jZ^{m-j}e^{ij\psi}.
\]

В коде `v16_1/dynamics.py` эти выражения вычисляются аналитически до второго порядка. Независимая проверка реализована второпорядковым forward-mode AD в `tests/test_v16_1.py` на дискретном симметричном распределении, причём потенциал AD суммируется по исходным зарядовым узлам, а не по тем же формулам моментов.

## Октуполь `m=4`

\[
\langle(Z+s e^{i\psi})^4\rangle=
Z^4+4\mu_1Z^3e^{i\psi}+6\mu_2Z^2e^{2i\psi}
 +4\mu_3Ze^{3i\psi}+\mu_4e^{4i\psi}.
\]

Следовательно, для чистого RO

\[
U_{4,RO}=\kappa_4\operatorname{Re}\!\left[e^{-i(\omega_4\tau-\delta_4)}
\left(Z^4+4\mu_1Z^3e^{i\psi}+6\mu_2Z^2e^{2i\psi}+4\mu_3Ze^{3i\psi}+\mu_4e^{4i\psi}\right)\right].
\]

Для симметричного стержня остаются только `Z^4`, `6 mu2 Z^2 exp(2i psi)` и `mu4 exp(4i psi)`. Искомый член в точности равен

\[
U_{COM,2}=6\kappa_4\mu_2\operatorname{Re}[Z^2e^{i(2\psi-\omega_4\tau+\delta_4)}].
\]

Для равномерного стержня коэффициент квадратичной гармоники `b=6 kappa4 mu2=kappa4 ell^2/2`. Он исчезает как `ell^2` при `L/R -> 0`; октупольный член `mu4` для вращения исчезает быстрее, как `ell^4`.

Для стоячего октуполя

\[
U_{4,SO}=\kappa_4\cos(\omega_4\tau-\delta_4)\operatorname{Re}[P_4(Z,\psi)].
\]

Тот же член `6 kappa4 mu2 Re[Z^2 exp(2i psi)] cos(omega4 tau-delta4)` присутствует, но его коэффициент меняется во времени. Поэтому автономное условие для RO нельзя переносить на SO; SO проверяется периодической стрельбой и монодромией.

## Квадруполь `m=2`

\[
\langle(Z+s e^{i\psi})^2\rangle=Z^2+2\mu_1Ze^{i\psi}+\mu_2e^{2i\psi}.
\]

Для симметричного стержня

\[
U_{2,RO}=\kappa_2\operatorname{Re}[e^{-i(\omega_2\tau-\delta_2)}(Z^2+\mu_2e^{2i\psi})],
\]

\[
U_{2,SO}=\kappa_2\cos(\omega_2\tau-\delta_2)\operatorname{Re}[Z^2+\mu_2e^{2i\psi}].
\]

Здесь центр масс уже имеет линейную RF-силу для точечного заряда: гессиан по `x,y` не зависит от размера стержня. Конечный размер добавляет ориентационную энергию `mu2`, но не создаёт новый COM-квадратичный член. Для чистого QRO и равномерного стержня угловой порог при `omega2=1` равен `gamma_rot,c=4 abs(kappa2)`; вывод приведён в `ROTATIONAL_LOCKING_RU.md`.

## Проверки

- Прямое суммирование исходного полинома по симметричным зарядовым узлам совпало с разложением моментов для `m=2,4`.
- Потенциал, все три компоненты градиента и полный `3x3` гессиан совпали с независимым второпорядковым AD: максимальные относительные расхождения теста ниже `4e-12`.
- Силы и момент определяются одним и тем же потенциалом; численный момент в существующем V16 quadrature-коде дополнительно совпадает с конечной производной энергии.

## Граница применимости

Это точная двумерная модель прямого однородного электрического гармонического потенциала и закреплённого линейного зарядового профиля. Она не описывает электродные края, высшие пространственные гармоники, несимметрию зарядов, трёхмерные вращения или распределённый газовый момент; эти ограничения особенно существенны для экспериментальной экстраполяции.
