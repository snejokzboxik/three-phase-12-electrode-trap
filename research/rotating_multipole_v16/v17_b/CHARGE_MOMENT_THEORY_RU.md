# Универсальная теория подписанных моментов заряда

**Статус:** `COMPLETED` для плоского жёсткого тела и идеального 2D гармонического поля.

Пусть `s_i` — комплексные координаты зарядов относительно механического центра масс в body frame, `q_i` — их знаковые заряды, `Z=(X+iY)/R`, а `ψ` — угол тела. Центр масс не выводится из зарядов и должен быть задан отдельно. Берём `q_ref=Σ_i|q_i|>0` и

`C_j = Σ_i (q_i/q_ref)(s_i/R)^j`.

`C_0=Q/q_ref` может быть нулём; нормирование на `Q` для нейтрального тела не используется. Для потенциала поля `V_m(z,t)=V_m Re[(z/R)^m exp(−i(ωt−δ))]` взаимодействие, с коэффициентом `κ_m` уже включающим масштаб `q_ref V_m`, равно

`U_m=κ_m Re{exp[−i(ωt−δ)] Σ_(j=0)^m binom(m,j) C_j Z^(m−j) exp(ijψ)}`.

Это следует непосредственно из бинома для каждого `q_i`; символически коэффициент при `Z^(m−j)exp(ijψ)` есть `binom(m,j) C_j`. Независимая проверка прямой суммой по точечным зарядам для `m=1…8` дала максимум `6.94×10⁻¹⁸`.

В центре `Z=0` остаётся только `κ_m Re[C_m exp(i(mψ−ωt+δ))]`. Поэтому `C_m` задаёт вращающий момент, а единственный член линейный по `Z` пропорционален `C_(m−1)` и создаёт силу в центре. Квадратичная COM-энергия пропорциональна `binom(m,2) C_(m−2)`. Для нулевой центральной силы, момента синхронизации и линейной COM-локализации одновременно необходимы `C_(m−1)=0`, `C_m≠0`, `C_(m−2)≠0`.

При синхронизации `ψ=ωt/m+φ` вводим `u=exp(−iωt/m)Z`. Тогда локальный квадратичный член стационарен:

`U_COM^(2)=Re[B_m u²]`, `B_m=binom(m,2)κ_m C_(m−2) exp[i((m−2)φ+δ)]`.

Его вещественный гессиан имеет собственные значения `±2|B_m|`. Это rotating-quadrupole форма локальной динамики; знак одного направления кривизны сам по себе не означает неустойчивость, потому что вращающаяся система вносит центробежный и кориолисов члены.

Для синхронного режима при `ω≠0` порог момента сопротивления в нормировке `τ=ωt`, `I` — заданный момент инерции:

`γ_rot,c = m² |κ_m C_m|/(I |ω|)`.

Это равенство относится к амплитуде поля, заданному телу и принятому определению `κ_m`. Физически равное напряжение и равное безразмерное `κ_m` — разные сравнения.

**Ограничение:** 2D-комплексные моменты кодируют выбранный плоский срез. Полный 3D STF-тензорный вывод и конечные формы с толщиной здесь не построены.
