# Нейтральный конечный диполь в RO3

**Статус:** `COMPLETED` для локального синхронного решения и линейного спектра; нелинейная область захвата исследована только пилотно.

Берём два заряда `+q` и `−q` в точках `+a` и `−a`, `q_ref=2q`. Тогда `C_0=0`, `C_(2k)=0`, `C_(2k+1)=(a/R)^(2k+1)`. Для чистого бегущего поля порядка `m=3`:

`P_3=Z³+3(a/R)Z²exp(iψ)+(a/R)³exp(3iψ)`.

При `Z=0` сила нулевая, поскольку `C_2=0`; вращающий момент ненулевой через `C_3`; член `3(a/R)Z²` создаёт центральную COM-локализацию. В бегущем со скоростью `ω/3` базисе это точный квадратичный потенциал с `|b|=3|κ_3|a/R`.

Для `a/R=0.1`, `ell/R=0.2`, `κ3=0.03`, `ω=1`, `I=ell²/12`, `γtrans=0.05`, `γrot=0.02` получены `γrot,c=0.081`, `|b|=0.009`, синхронная фаза `φ=0.9640329112475025 rad` (см. JSON). Спектр вращающегося 6D-якобиана: `−0.025±0.34246869i`, `−0.025±0.32200531i`, `−0.01±0.27998578i`. Все моды асимптотически затухают.

Лабораторная вариационная система DOP853 интегрирована на `T=6π` (три периода RF, чтобы вернуть произвольную полярную конфигурацию тела). Максимальное согласование мультипликаторов с `exp(sT)` равно `2.92e−14`; невязка орбиты `1.99e−13`.

Контраст с чистым полем порядка `m=4` (октуполь): для того же нейтрального диполя `C_3=(a/R)^3≠0`, значит возникает ненулевая периодическая сила в центре; `C_4=0` не даёт центрального синхронного момента, а `C_2=0` устраняет квадратичный член. Таким образом, эта конкретная комбинация симметрии диполя и RO3 не переносится автоматически на октуполь `m=4`.

При равном иллюстративном `κ=0.03` амплитуда центра-силы для m=4 равна `mκ|C3|=1.2e−4`, тогда как `mκ|C4|=0`: нет torque для синхронизации ровно в центре. Для m=3 сила равна нулю, torque-amplitude `9e−5`, а квадратичный коэффициент `|b|=9e−3`. Это равные безразмерные coefficients, не равные физические напряжения.

Масштабный предел зависит от фиксируемой величины. При фиксированных `q_i/q_ref` и фиксированном `κ` член локализации `b∝a/R` исчезает при `a/R→0`, а момент тела `κ C_3∝(a/R)^3` исчезает быстрее. Если вместо этого удерживать физический дипольный момент постоянным, нужно увеличивать `q∝1/a`; это меняет `q_ref`, нагрузку на ловушку и физический коэффициент `κ`, поэтому это иной предел, а не фиксированный заряд.

Результат пилота 1000 RF приведён в `results/basin_local_summary.json`: 6/6 малых возмущений захвачены, 0 выходов; Wilson 95% интервал `[0.610,1.000]`. Один широкий старт в `results/basin_pilot_checkpoint.json` не синхронизировался, хотя COM остался у центра. Это не определяет глобальную долю захвата.
