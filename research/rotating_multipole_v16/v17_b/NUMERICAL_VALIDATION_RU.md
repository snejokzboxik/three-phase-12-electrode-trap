# Численная валидация

**Статус:** `COMPLETED` для аналитического RO3-среза; широкий V17B verification suite `PARTIAL`.

- Разложение моментов против прямой суммы charge sites: максимум `6.94e−18` по случайным тестовым конфигурациям, порядки 1–8.
- Градиент энергии против центральных конечных разностей: максимум `5.05e−14`.
- Hessian против конечных разностей градиента/энергии: максимум `2.04e−12` в анализе; unit-test критерии слабее и выполнены.
- Полный текущий набор V16/V16.1/V17B unit tests: `22 passed in 43.58s` (`python -m pytest -q`). Новые длительные сценарии частотного чирпа и reversal проверены отдельными повторными DOP853 интеграциями, но не добавлены в 22 unit tests. Периодическая SO3 shooting-валидация отдельно дала closure `<7.2e−15`, coarse/fine Floquet matching `≤9.4e−15`, `max |μ|=0.9093354` для обоих направлений.
- 6D аналитический якобиан: спектр указан в JSON и `DIPOLE_DYNAMICS_RU.md`.
- Независимая лабораторная монодромия: DOP853; точная relative-orbit closure `1.99e−13`; matching `exp(sT)` `2.92e−14`.
- Нелинейный пилот: DOP853 на `1000 RF`, 6/6 малых начальных perturbations captured для трёх independent seeds. Wilson CI `0.610–1.000`; один широкий независимый старт не locked. Оценка большого бассейна не завершена.
- Новый запуск из покоя: точная центральная редукция интегрирована по 360 ориентациям (120 различных резонансных фаз); контрольные частоты `Ω=0.5`, `0.55`, `3.5` проверены до `10 000 RF`. Это сеточная доля покрытия, не биномиальная статистика.
- Полный 6D чирп `Ω=0.4→3.5`: DOP853, `rtol=2e-9`, `atol=2e-11`, `max_step=0.5`, полный output grid с промежутком не более `0.25`. Повтор с `rtol=3e-10`, `atol=3e-12`, `max_step=0.25` дал максимальное отличие конечного состояния `1.2733e-11`; в обоих вариантах конечная ошибка фазы меньше `1e-6 rad`, а ошибка spin меньше `6.7e-8`.
- Независимые нелинейные COM-старты при `Ω=0.5`: локальный спектр 6D устойчив, но выбрана узкая одномерная линия начальных состояний показывает захват при `d=0.001546875` и выход всей частицы через апертуру при `d=0.0015625`. Escape-time `330.78`; траектория для захваченного значения записана на всём 1000-RF интервале, где max COM `0.03663 R`.
- Направление вращения: полный 6D реверс `+0.5→−0.5` за `T=20` и `T=40` захватывается после 1000 RF; `T=80` покидает апертуру. Успешный `T=20` повторён с `max_step=0.25`, более строгими допусками и полным выходом: максимальная разность конечного состояния `9.095e-13`, phase-branch changes `0` в обоих расчётах.

Не выполнены проверка фазового восстановления после checkpoint/restart, периодические branch continuation и модуляционные решения для SO4/combined fields, классификация неразрешённых траекторий, независимый второй интегратор для полного chirp, физическая калибровка RF и 3D controls.
