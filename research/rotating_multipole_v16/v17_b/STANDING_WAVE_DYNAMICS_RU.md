# Стоячий SO3: модулированная синхронизация

**Статус:** `COMPLETED` для одной идеальной параметрической точки и обоих направлений; SO4/octupole карта `NOT_RUN`.

Рассмотрено `U=κ Re[P_3(Z,ψ)]cosτ`, где для neutral dipole `P_3=Z³+3a Z²e^{iψ}+a³e^{3iψ}`. В центре угловое уравнение вынужденно-параметрическое; строгое решение `ψ=±τ/3+φ` с постоянной `φ` не следует из RO-формулы. Усреднение даёт вращательный torque amplitude `3|κ|a³/2`, половину от односторонней RO3 гармоники.

Для `a/R=0.1`, `κ3=0.03`, `I=ell²/12`, `γtrans=0.05`, `γrot=0.02` выполнен shooting на период `T=6π`, чтобы полярный диполь вернулся после трёх RF циклов. Найдены оба направления со средним spin `±1/3`. Начальные состояния periodic orbit: `(ψ0,spin0)=(0.8733557302,0.3392969140)` и `(1.2210393722,−0.3392969140)`. Различие мгновенного spin и `±1/3` — периодическая phase modulation.

Независимая DOP853 вариационная монодромия по полной 6D модели (signed moments переданы явно) имеет для каждого знака максимум `|μ|=0.9093354138`; COM-часть даёт четыре модуля `{0.9093354,0.9093354,0.4285120,0.4285120}`, угловая пара `{0.8282042,0.8282042}`. Невязки замыкания `<7.2e−15`; повтор шага `T/800 → T/1600` меняет matching Floquet-мультипликаторы не более чем `9.4e−15`. Линейные COM–rotation cross-block элементы равны нулю при `C2=0`.

Нелинейный тест 1000 RF на трёх independent seeds и двух стартах на seed для каждого направления дал `6/6` захватов `+1/3` и `6/6` для `−1/3`, без aperture loss. Wilson 95% на направление `[0.610,1.000]`; это небольшой локальный ансамбль, не размер бассейна.

Результат не распространяется на SO4 neutral dipole, на распределение заряда с `C_(m−1)≠0`, на другие `γrot`, напряжения и реальные электроды. `results/standing_ro3_results.json` содержит shot residuals, multiplier arrays, coarse/fine check; `results/standing_basin_summary.json` — независимые seeds и trajectory diagnostics.
